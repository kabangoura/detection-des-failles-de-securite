Installation and scan guide

Choose your system. Follow the steps in order: each step says exactly what to do.

Allow about 5 minutes the first time. After that, only step 4 is needed (1 minute).

  1. Install Python (once)

    Python is free, official software that KMB needs to run.

    1. Open python.org/downloads and click the yellow Download Python button.
    2. Open the downloaded file.
    3. Important: at the bottom of the first window, check “Add python.exe to PATH”.
    4. Click Install Now, wait, then click Close.

    Already installed? Go to step 2. If you forgot the “Add python.exe to PATH” box, run the installer again, choose Modify, then check “Add Python to environment variables”.

  2. Open the Command Prompt

    Click the Windows Start button, type cmd and press Enter. A black window opens.

  3. Install KMB (once)

    Copy this command (“Copy” button), paste it into the black window (right-click) and press Enter:

    python -m pip install kmb-library

    Installation takes 1 to 3 minutes. It is done when you see Successfully installed … kmb-library. Yellow WARNING … is not on PATH messages may appear: they don't matter.

  4. Scan your computer

    python -m kmb_library scan

    KMB finds your computer name and all the information by itself. The scan takes 3 to 5 minutes (it examines all your disk space) and changes nothing.

    Next times: open the Command Prompt (step 2) and type only this command.

    Full check (optional): in the Start menu, type cmd, right-click “Command Prompt”, choose Run as administrator, then type the same command.

  5. See the result

    At the end, the Documents\KMB Library folder opens by itself. Your report is named, for example:

    KMB-rapport_DESKTOP-ABC123_2026-10-18_14h30.json

  1. Check Python

    Frequently asked questions

    Is my data sent over the Internet?

    No. The report is read by your browser, on your computer. This site neither sends nor stores it. The scanner only contacts the public endoflife.date site to find out software end-of-support dates (without sending anything personal).

    The only exception, if you agree: the AI assistant. See the next question.

    How does the AI assistant work?

    The 🤖 buttons (“Explain this problem to me”, “Summarise my report”, fix plan, questions, comparison) use an AI. The first time, the site asks for your consent. It then sends an anonymous summary of the problems detected (title, severity, finding, known fix commands): never the computer name, accounts, IP addresses, your files or the full report.

    This summary goes through the KMB Library relay, which sends it to the Groq AI service (open models) and returns the answer; nothing is stored. AI can be wrong: KMB checks that every step matches a real problem from the scan and flags any command missing from its verified database. The number of requests is limited (10 per hour) so that the service stays free for everyone.

    Can the scanner damage my computer?

    No. It reads information and changes nothing. Fixes are suggested: you decide whether to apply them.

    Why do I need to install Python?

    KMB Library is a Python library, like many computer tools. Python is installed from its official website, then a single command installs KMB from PyPI, the official Python software repository: no unknown program to open, and KMB's code stays open to inspection.

    “python” is not recognized, or the Microsoft Store opens?

    Python is not installed, or the “Add python.exe to PATH” box was not checked. Run the Python installer again, choose “Modify”, check “Add Python to environment variables”, then close and reopen the Command Prompt.

    How do I update or uninstall KMB?

    Update: python -m pip install --upgrade kmb-library. Uninstall: python -m pip uninstall kmb-library.

    To look at the code: download KMB Library (ZIP).

    What does “not checkable” mean?

    Some checks require administrator rights. For a full check, run the scan from a Command Prompt opened “as administrator” (see the guide, step 4). These checks don't cost any points.

    How can I see my progress after my fixes?

    Scan again, then in “Analyse my report”, add the old and the new report. The “Comparison” tab shows what is fixed, what remains and what is new.

    Which file should I choose?

    The file that starts with KMB-rapport_ and ends with .json: it is your report, and this site displays it. The donnees-brutes folder (raw data) and the .cache folder are only used internally and for verification.

    🤖 Use the AI assistant?

    To answer you, KMB sends the AI an anonymous summary of the problems detected: their title, severity, finding and known fix commands.

    • Never sent: the computer name, accounts, IP addresses, your files or the full report.
    • The KMB relay passes this summary to the Groq AI service, then returns the answer. Nothing is stored.
    • AI can be wrong: every answer is checked by KMB, and unknown commands are flagged.

    Without your consent, nothing is sent and the rest of the report works normally.
