Votre ordinateur est-il bien protégé ?

KMB Library vérifie gratuitement la sécurité, les logiciels, la performance et le stockage de votre ordinateur, puis vous explique simplement quoi corriger, étape par étape.

Ce que KMB vérifie

  • Système : votre Windows/macOS/Linux reçoit-il encore des mises à jour de sécurité ?
  • Protection : antivirus, pare-feu, chiffrement du disque, comptes
  • Réseau et Wi-Fi : services exposés, réseau Wi-Fi non protégé
  • Logiciels : programmes obsolètes ou plus mis à jour par leur éditeur
  • Performance : mémoire, processeur, programmes au démarrage, batterie
  • Stockage : espace libre, fichiers en double, gros fichiers

Guide d'installation et de scan

Choisissez votre système. Suivez les étapes dans l'ordre : chaque étape dit exactement quoi faire.

Comptez environ 5 minutes la première fois. Les fois suivantes, seule l'étape 4 est nécessaire (1 minute).

  1. Installez Python (une seule fois)

    Python est un logiciel gratuit et officiel qui permet à KMB de fonctionner.

    1. Ouvrez python.org/downloads et cliquez sur le bouton jaune Download Python.
    2. Ouvrez le fichier téléchargé.
    3. Important : en bas de la première fenêtre, cochez « Add python.exe to PATH ».
    4. Cliquez sur Install Now, attendez, puis sur Close.

    Déjà installé ? Passez à l'étape 2. Si vous avez oublié la case « Add python.exe to PATH », relancez l'installateur, choisissez Modify puis cochez « Add Python to environment variables ».

  2. Ouvrez l'invite de commandes

    Cliquez sur le bouton Démarrer de Windows, tapez cmd puis appuyez sur Entrée. Une fenêtre noire s'ouvre.

  3. Installez KMB (une seule fois)

    Copiez cette commande (bouton « Copier »), collez-la dans la fenêtre noire (clic droit) et appuyez sur Entrée :

    python -m pip install {URL_ZIP}

    L'installation prend 1 à 3 minutes. C'est terminé quand vous voyez Successfully installed … kmb-library. Des messages jaunes WARNING … is not on PATH peuvent apparaître : ils sont sans importance.

  4. Scannez votre ordinateur

    python -m kmb_library scan

    KMB trouve tout seul le nom de votre ordinateur et toutes les informations. Le scan dure 1 à 3 minutes et ne modifie rien.

    Les fois suivantes : ouvrez l'invite de commandes (étape 2) et tapez seulement cette commande.

    Examen complet (facultatif) : dans le menu Démarrer, tapez cmd, faites un clic droit sur « Invite de commandes », choisissez Exécuter en tant qu'administrateur, puis tapez la même commande.

  5. Voyez le résultat

    À la fin, le dossier Documents\KMB Library s'ouvre tout seul. Votre rapport s'appelle par exemple :

    KMB-rapport_DESKTOP-ABC123_2026-10-18_14h30.json

    Analyser mon rapport puis choisissez ce fichier.

  1. Vérifiez Python

    Ouvrez un terminal :

    python3 --version

    Ubuntu / Debian, si nécessaire :

    sudo apt install python3-venv

  2. Installez KMB (une seule fois)

    KMB s'installe dans son propre dossier ~/.kmb, sans toucher au Python du système. Copiez les deux lignes, une à la fois :

    python3 -m venv ~/.kmb
    ~/.kmb/bin/python -m pip install {URL_ZIP}

  3. Scannez

    ~/.kmb/bin/python -m kmb_library scan

    Examen complet : sudo ~/.kmb/bin/python -m kmb_library scan

  4. Voyez le résultat

    Votre rapport est dans ~/Documents/KMB Library : téléversez le fichier KMB-rapport_….json.

    Questions fréquentes

    Mes données sont-elles envoyées sur Internet ?

    Non. Le rapport est lu par votre navigateur, sur votre ordinateur. Il n'est ni envoyé ni conservé par ce site. Le scanner contacte seulement le site public endoflife.date pour connaître les dates de fin de support des logiciels (sans rien envoyer de personnel).

    Le scanner peut-il abîmer mon ordinateur ?

    Non. Il lit des informations, il ne modifie rien. Les corrections sont proposées : c'est vous qui décidez de les appliquer.

    Pourquoi faut-il installer Python ?

    KMB Library est une librairie Python, comme beaucoup d'outils informatiques. Python s'installe depuis son site officiel, puis une seule commande installe KMB directement depuis ce site : pas de programme inconnu à ouvrir, et le code de KMB reste consultable.

    « python » n'est pas reconnu, ou le Microsoft Store s'ouvre ?

    Python n'est pas installé, ou la case « Add python.exe to PATH » n'a pas été cochée. Relancez l'installateur de Python, choisissez « Modify », cochez « Add Python to environment variables », puis fermez et rouvrez l'invite de commandes.

    Comment mettre KMB à jour ou le désinstaller ?

    Mise à jour : reprenez la commande de l'étape 3 en ajoutant --upgrade après install. Désinstallation : python -m pip uninstall kmb-library.

    Pour consulter le code : télécharger KMB Library (ZIP).

    Que veut dire « non vérifiable » ?

    Certains contrôles exigent les droits d'administrateur. Pour un examen complet, lancez le scan depuis une invite de commandes ouverte « en tant qu'administrateur » (voir le guide, étape 4). Ces contrôles ne retirent aucun point.

    Comment voir mes progrès après mes corrections ?

    Refaites un scan, puis dans « Analyser mon rapport », ajoutez l'ancien et le nouveau rapport. L'onglet « Comparaison » montre ce qui est corrigé, ce qui reste et ce qui est nouveau.

    Quel fichier dois-je choisir ?

    Le fichier qui commence par KMB-rapport_ et finit par .json : c'est votre rapport, et ce site sert à l'afficher. Le dossier donnees-brutes (données de départ) et le dossier .cache servent uniquement au fonctionnement et à la vérification.
